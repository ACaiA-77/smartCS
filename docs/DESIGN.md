# SmartCS 服务台主题

## 1. 氛围

面向客户的智能客服服务台，像一张清楚、可靠的工作桌。深色导航负责定位，浅色对话区负责阅读，订单上下文保持安静。

## 2. 色彩

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Navy | `#142c3d` | 品牌区与侧栏 |
| Ink | `#1d3342` | 正文与标题 |
| Canvas | `#f1f5f6` | 页面背景 |
| Blue | `#176b8a` | 主操作与客户消息 |
| Soft blue | `#e7f1f4` | 轻量提示 |
| Apricot | `#efb98f` | 品牌标记 |
| Line | `#dbe4e9` | 分隔线 |

成功、警告和错误仍使用 `styles.css` 中独立的语义色，不把品牌蓝当成状态色。

## 3. 字体

使用 `Segoe UI`, `Microsoft YaHei UI`, `Noto Sans SC`, `sans-serif`。正文 14px、行高约 1.75；小标签 11–13px；工作区标题 18–22px；登录品牌标题 36–58px。中文标题不压缩字间距。

## 4. 组件

按钮、输入和消息气泡使用 8–10px 圆角。主按钮为蓝底白字，次要操作为白底浅边；禁用态保留可读文字。所有操作保留键盘焦点框、按压反馈和至少 40px 的点击高度。

## 5. 布局

桌面端为导航、对话、订单上下文三栏。对话是唯一主工作区，消息宽度不超过 820px；左右栏只放导航与辅助信息，不复制聊天内容。

## 6. 层次

主要靠背景色阶和细分隔线区分区域。消息气泡仅用极浅阴影；普通区块不套统一卡片。

## 7. 边界

- 只改变界面表达，不暗示存在人工客服或新增业务能力。
- 不使用渐变字、玻璃卡、粗侧边装饰或统一的大阴影卡片。
- 不用动画延迟发送、切换会话、输入和键盘操作。
- 客户消息与 AI 消息保持不同的颜色和位置。
- 状态色只表达真实状态。

## 8. 响应式

1120px 以下将订单上下文移到对话下方，页面可滚动访问；760px 以下导航变为顶部紧凑区，对话输入保留在首屏底部。375px 宽度需检查登录、消息和输入框。

## 9. 后续界面提示

- 新增侧栏入口：`#142c3d` 背景，文字 `#a8bdc9`，40px 高，8px 圆角，选中态浅白色背景。
- 新增主操作：`#176b8a` 背景、白字、48px 高、8px 圆角，保留焦点框和按压反馈。
- 新增上下文行：放在 `#f9fbfc` 区域，使用 `#dbe4e9` 分隔线，不另加卡片阴影。
