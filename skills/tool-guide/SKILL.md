# 工具选择说明

## knowledge_search

- 用途：检索**共享**企业知识库（政策文档、产品说明、操作指引）。它不查询任何客户个人数据。
- 查询写法：用业务名词而非整句口语（"退款到账时间"优于"我的钱什么时候能退回来"）。
- 域过滤：不确定时不要传 domain/domains，先全库检索；检索不到再收窄。
- 结果解读：返回片段带来源文件；答复时引用来源，不要凭记忆补全政策细节。

## 工具选择

| 客户诉求 | 该用的工具 |
|---|---|
| 政策/流程/产品说明 | knowledge_search |
| 我的订单状态/物流 | order_query |
| 我的工单进度 | ticket_query |
| 退款条件评估 | refund_evaluate（评估，不等于执行） |

- 需要客户个人数据的问题，一律用对应业务工具，不要用 knowledge_search 代替。
- 工具返回失败时如实告知并给出下一步，不要编造结果。

## 边界

本技能只提供**选哪个工具、怎么问**的建议；是否允许执行、执行结果如何，由业务系统决定。
